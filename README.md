# AI 提示词 Markdown 编辑器（AiPromptMarkdownEditor）

面向「AI 结构化提示词拼接与整理」场景的 Windows 桌面 Markdown 编辑器。
在文档中组织 `<system>` / `<user>` 等标签块与 Markdown 结构，最终产出可直接粘贴给 AI 的大段提示词文本。支持多文档多标签页同时编辑。

## 技术选型

| 组件 | 说明 |
|---|---|
| .NET 10 + WPF + C# | MVVM 架构（轻量自研 ObservableObject / RelayCommand，不引入 MVVM 框架） |
| AvalonEdit | 文本编辑核心：行号、语法高亮、折叠、大文本性能、独立撤销栈 |
| Markdig | Markdown 解析：大纲提取（标题行号）、结构分析 |

**NuGet 依赖（刻意最少）：**
- `AvalonEdit`（6.3.1.120）：需求固定选型的编辑核心控件（ICSharpCode.AvalonEdit 自 6.x 起的官方包 ID）
- `Markdig`（0.41.x）：需求固定选型的 Markdown 解析库
- 测试：`xunit` / `xunit.runner.visualstudio` / `Microsoft.NET.Test.Sdk`（仅测试工程）

## 项目结构

```
AiPromptMarkdownEditor/
├─ AiPromptMarkdownEditor.slnx        # 解决方案（.NET 10 新格式）
├─ src/
│  ├─ PromptEditorLib/                # 纯逻辑库（无 UI 依赖，可单测）
│  │  ├─ Tags/       标签定义、标签库、配对扫描、包裹/移除运算
│  │  ├─ Text/       行尾检测与统一、token 估算
│  │  ├─ Markdown/   大纲提取、折叠区域计算、标题/行内标记/列表/表格操作
│  │  └─ Tabs/       标签页显示名同名消歧
│  └─ PromptEditorApp/                # WPF 应用（net10.0-windows）
│     ├─ ViewModels/   MainViewModel / DocumentViewModel（每标签一个 TextEditor 实例）
│     ├─ Views/        设置、标签库、标签选择器、表格、快速跳转、未保存列表等窗口
│     ├─ Controls/     行尾显示生成器（cat -A 风格）、查找高亮/闪烁渲染器
│     ├─ Services/     设置持久化、文件读写（BOM 探测/编码保留）、编辑操作
│     └─ Themes/       深色/浅色主题资源 + 内置 Markdown 语法高亮定义
└─ tests/PromptEditorLib.Tests/       # 单元测试（80 个）
```

## 构建与运行

```bash
# 需要 .NET 10 SDK（10.0.4xx+），Windows 平台运行
dotnet build AiPromptMarkdownEditor.slnx -c Release
dotnet run --project src/PromptEditorApp -c Release

# 运行单元测试（任何平台）
dotnet test tests/PromptEditorLib.Tests
```

> 仓库已在 Linux CI 环境通过 `EnableWindowsTargeting` 完成编译验证与全部单元测试；
> WPF 运行仍需 Windows。启动参数可直接带文件路径：`PromptEditor.exe a.md b.md`。

## 功能清单

### 标签功能（核心）
- 标签四字段：短名 / 开始标签 / 结束标签 / 包裹方式（块级、行内）；内置 system、system_reminder、user、assistant、tool 预设，均可编辑/删除，「恢复默认」一键还原
- 校验：短名唯一非空、起止标签非空且互不相等（错误阻止保存）；开始标签跨标签重复给出警告（允许保存）
- 标签库持久化本地 JSON，支持导入 / 导出；修改定义不回溯已打开文档文本，仅影响后续插入与检测类功能
- 「更多标签…」窗口内通过「标签库管理…」修改并保存标签库后会自动持久化（无论是否应用了标签）；标签库管理保存前会提交表格未确认的编辑，防止内容丢失
- 右键「插入标签」按短名列出（置顶优先）；块级包裹 `开始\n选中\n结束`，行内紧贴；无选区插入空标签对、光标居中（块级在中间空行）
- 「移除标签」：光标在标签对内部或选区完整包含一对时移除最内层配对，保留内容
- 「更多标签…」弹窗过滤：匹配短名 + 实际起止标签文本，列表项显示短名与实际标签预览，入口直达标签库管理
- 工具栏标签下拉框支持文本过滤：可编辑，输入短名做包含匹配（忽略大小写），选中后自动清空过滤便于连续使用
- 右键「外围标签」子菜单顶部提供过滤输入框，动态筛选标签短名列表；超长列表限高可滚动，每次展开重建并聚焦过滤框
- 配对高亮见「已知限制」
- 标签不配对时不可折叠，状态栏提示首个错误行号

### Markdown 格式化（右键，均可创建/更改/移除）
- 标题：H1~H6、升级/降级、移除（去 # 保留文字）
- 加粗 `**` / 斜体 `*` / 删除线 `~~`：切换语义（已格式化再次点击即移除）；无选区插入空标记光标居中
- 无序 / 有序列表：多行逐行添加/移除前缀；有序列表自动重新编号；Tab / Shift+Tab 调整层级
- 表格：对话框创建（行/列/表头，光标落第一个单元格）；光标在表格中增删行、增删列；移除表格转纯文本行（保留单元格文字，分隔行忽略）

### 快速跳转
- 左侧大纲面板（可折叠）：标题（按级别缩进）+ 顶层标签 + 行号；点击滚动定位并短暂高亮目标行
- Ctrl+P：模糊匹配标题/标签；`:数字` 直接跳行
- Ctrl+G：跳转指定行号

### 行尾显示与统一
- 行尾显示开关（仿 cat -A：CRLF→`^M$`、LF→`$`、CR→`^M`），浅色修饰、纯显示不改文本；复制/保存永远输出真实文本
- 状态栏显示行尾类型；混合时显示「混合」，点击定位首个混合处
- 「统一行尾」（CRLF / LF）：仅替换不一致的分隔符，单步可撤销
- 新建文件默认 LF（可改）

### 折叠 / 展开
- 可折叠：成对标签、``` 代码围栏、标题章节（至下一个同级或更高级标题前）
- 折叠原位显示摘要：`<system> ⋯ 已折叠 32 行`
- 纯显示行为，不改动内容；Ctrl+M 折叠/展开光标所在区域，菜单全部折叠 / 全部展开

### 编辑器基础
- 多级撤销/重做（按标签页独立）；查找/替换（大小写、全字、正则、循环查找、全部替换，匹配全高亮）
- Markdown 高亮（深/浅两套配色）、行号开关、当前行高亮、软换行开关（默认关）
- Ctrl+滚轮缩放字号、Ctrl+0 复位；Tab 默认 4 空格（可配置为制表符）
- 状态栏：光标行列、选中字符/行数、总字符/行数、行尾类型、编码、token 估算（标注「估算值」）

### 多标签页
- 标签栏位于工具栏与编辑区之间；未保存显示 `*`；始终保留至少一个标签
- Ctrl+N / Ctrl+W / Ctrl+Tab / Ctrl+Shift+Tab / Ctrl+Shift+T（仅恢复磁盘文件标签）；中键点击关闭；拖拽排序；超宽可滚动 + 下拉列表快速选择；超长名末尾截断省略，tooltip 显示完整路径与修改状态
- 未命名标签编号取当前未被占用的最小编号；同名消歧按需求 8.2 算法（含「…」前缀规则、关闭后自动回缩），纯函数 + 单元测试
- 每标签独立状态：内容、撤销栈、光标/选区/滚动、折叠、路径/编码/行尾/修改标记——切换不重载不闪烁
- 关闭保护：单标签「保存/不保存/取消」；窗口关闭多未保存「全部保存/全部放弃/取消」；标题栏同步显示文档名与 `*`
- 标签右键：关闭、关闭其他、关闭右侧、复制完整路径、在资源管理器中显示

### 文件与编码
- 新建/打开/保存/另存为；.md、.txt 及任意文本文件；所有打开入口均新开标签、多选逐个开签
- 同一文件不重复打开（完整路径不区分大小写比较，已存在则激活）
- 另存为更新路径与显示名并触发消歧重算
- 编码：默认 UTF-8（无 BOM）；打开探测 BOM 并保留原编码；支持转换另存

## 性能设计（20 万字符文档）

- 编辑核心为 AvalonEdit，打开/输入/滚动/折叠满足验收指标
- 大纲解析、折叠计算、标签配对在文本变更后防抖（≈350ms）并放入后台线程，仅回 UI 线程应用结果；非激活标签不刷新大纲
- 查找匹配高亮防抖刷新并限制最大匹配数量；查找文本变更后台计算
- 同一解决方案内单元测试覆盖：标签配对解析、行尾检测与统一、折叠区域计算、表格操作、有序列表重编号、同名消歧

## 已知限制

- 配对高亮（光标位于标签上高亮对偶标签）依赖 AvalonEdit 二次渲染管线，当前版本未启用，属已知缺口；折叠、移除、状态栏错误行号提示等基于配对检测的功能不受影响
- 标题仅支持 ATX（`#`）风格；setext（下划线）风格不识别
- 无 BOM 文件按 UTF-8 读取，不做编码猜测；如需其他编码请用「另存为（编码转换）」
- 斜体 `*` 与加粗 `**` 的切换判定基于精确前缀/后缀匹配，`*斜体*` 与 `**加粗**` 叠加时需手动处理
- 查找的「全字匹配」以 `\b` 实现，对以标点起止的查找词边界语义可能与预期略有差异
- 有序列表重编号以列表起始行为基准从其原编号起连续编号
- 标签栏拖拽排序基于鼠标拖放，与触控场景的兼容未做专项优化
